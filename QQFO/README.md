# QQFO extensions

This directory is the home for MaaQQFO-specific controller, Agent and game-state source. Keep shared desktop behavior in the upstream projects and wire product-specific entry points where the upstream interfaces require them.

The current development baseline builds the upstream client. Verification/packaging entry points live in `tools/` and results in `docs/validation/`. Start with the [A1 review record](../docs/validation/STAGE_A1_REVIEW.md) and [dependency baseline](../docs/engineering/DEPENDENCY_BASELINE.md).
