# A2/A3 QQ幻想实机验收准备

状态：待接入实际 P8.3 后端并通过 Windows 自有窗口验收。本页用于准备，执行前需有可复现的客户端构建和实际后端。

## 提前准备

- 准备一个 QQ幻想角色，登录后停在可安全移动的空旷区域。关闭交易、战斗和其他需要保护的游戏操作。
- 可选准备第二块设为不同 Windows 缩放比例的显示器，用于 A2 跨屏 DPI 专项。单显示器仍可验收连接、分辨率、截图、点击和重连。

## 同一轮执行

1. 记录客户端构建、游戏 PID/HWND、客户区尺寸、DPI 和截图模式。选定三个可安全到达的点 A、B、C，并记录截图上各点的 MaaImage 坐标。
2. 由用户确认首次对该游戏进程启用实际输入后端。将游戏置于后台，使用同一个 Maa Pipeline 的原生 Click 节点依次点击 A、B、C。每个点记录预期坐标、实测动作和结果。
3. 比对每次点击前后的前台窗口和物理鼠标坐标。执行阶段短暂保持桌面安静。记录 Hook 释放结果，确认游戏能继续正常接收人工输入。
4. 重建一次游戏窗口并重新选择，检查旧会话失效、重新连接与截图。具备双屏条件时在不同缩放比例间再验证一次截图和坐标。

实机证据应能关联具体构建、测试结果及目标窗口。实机未运行的项目保留待验证状态。
